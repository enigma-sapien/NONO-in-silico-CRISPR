# Proposed validation plan

## Scope

This is a conceptual plan for future supervised experimental work.

No genome editing or laboratory validation was performed.

## Pre-experimental checks

Before laboratory testing:

- Verify the reference assembly and target coordinates
- Confirm the intended NONO transcript and coding exon
- Verify spacer sequences and PAMs
- Review complete predicted off-target lists
- Select an appropriate biological model
- Define controls, biological replicates, and outcome measures

## On-target validation

A future experiment would require sequencing-based confirmation of
changes at the intended genomic locus.

A possible strategy would involve:

1. Designing locus-specific PCR primers around the target region
2. Checking predicted primer specificity
3. Amplifying the target locus after editing
4. Using Sanger sequencing or targeted amplicon sequencing
5. Analysing the resulting alleles or indel distribution

No primer sequences have been validated in this project.

## Functional validation

Detection of an indel would not by itself establish a functional knockout.

Further assessment could include:

- Determining whether the edit disrupts coding sequence
- Assessing NONO transcript abundance
- Assessing NONO protein abundance
- Evaluating relevant molecular readouts in the selected model

## Controls and interpretation

The experimental design should include appropriate negative controls
and independent guides.

Any phenotype should be interpreted only after confirming on-target
editing and considering guide-specific or off-target effects.

## Off-target follow-up

Priority predicted off-target sites would require separate experimental
assessment where appropriate.

Computational predictions do not demonstrate experimental specificity.
