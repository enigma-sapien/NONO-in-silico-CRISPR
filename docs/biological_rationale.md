# Biological rationale

## Background

NONO was selected from candidate genes examined during my master's
thesis-related work on intellectual disability. Other candidate genes
included SLC7A3, MED12, and NLGN3.

This project extends that candidate-gene work into computational
functional-genomics planning.

## Project purpose

The purpose is to develop and document a reproducible workflow for:

- Selecting a genomic target region
- Generating candidate SpCas9 guide RNAs
- Reviewing predicted activity and specificity
- Inspecting predicted off-target sites
- Comparing candidate guides using Python
- Planning future experimental validation

## Research question

Can a documented computational workflow identify candidate guide RNAs
that could support a future study of NONO function?

## Proposed biological direction

A future loss-of-function study could investigate the molecular effects
of reducing or disrupting NONO function in an appropriate cellular model.

However, a knockout-oriented design requires confirmation that the
selected guides target a relevant coding exon of the intended transcript.

## Current scope

This repository is a computational design and learning project.

It does not establish:

- That NONO was edited
- That the selected region is a verified coding exon
- That a candidate guide produces a knockout
- That NONO disruption causes a particular phenotype

Published biological background and supporting references should be
reviewed and added before making detailed mechanistic claims.
