# Analysis outputs

## guide_ranking.csv

Generated by scripts/rank_guides.py.

The table contains the candidate data, a GC-deviation penalty, and a
custom composite score.

These scores are preliminary because the original CRISPOR score-column
identities and sequence-derived GC percentages still require verification.

The composite score is not a measure of editing efficiency or safety.

## guide_selection_summary.csv

Records the current review status of each candidate.

No final experimental guide has been selected.

## Reproducibility

Regenerate the ranking table using:

python scripts/rank_guides.py
